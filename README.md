# WigiDashWidgetFramework (legado)

> **Este repositório é legado.** Ele guarda o SDK v1 (net472) dos widgets para o WigiDash Manager oficial da
> G.SKILL, que foi descontinuado. Não recebe mais versões novas.
>
> Para criar widgets para o [OpenWigiDashManager](https://github.com/victorperez2911/OpenWigiDashManager)
> (.NET 10), use o pacote [`victorperez2911.OpenWigi.Sdk`](https://www.nuget.org/packages/victorperez2911.OpenWigi.Sdk)
> no nuget.org. A documentação está em
> [docs/sdk.md](https://github.com/victorperez2911/OpenWigiDashManager/blob/main/docs/sdk.md).

O pacote `victorperez2911.WigiDashWidgetFramework` continua disponível para quem mantém widgets net472
(por exemplo, as branches `legacy-net472` dos widgets Discord, Stream Deck Mirror e WebPage).
